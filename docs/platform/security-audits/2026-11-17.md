## SR000657 (ITSM) — measured, not a closure

Live on `irjrcskfcyierdbefrpk`, migration `20261113110555` (commit `64022116`, 2026-11-13, in `gca-ltd/matrix-itsm`).

- `get_current_user_email()` reads the email only when `email_verified` is the text `true`. `search_path=public`. It is not SECURITY DEFINER.
- `user_can_access_ticket` and `user_can_access_ticket_by_role` are SECURITY DEFINER, `search_path=public`, anon EXECUTE **false**.
- `ticket_comments_select` is `user_can_access_ticket` AND (`NOT is_internal` OR `user_can_access_ticket_by_role`). The email path does not see internal comments.
- `tickets_select` includes `lower(created_by_email)`. `tickets_update` does not.
- `trg_requester_reply_flip_status` is SECURITY DEFINER, `search_path=public`, anon EXECUTE false. It updates the ticket only when the new comment is not internal, the ticket is `waiting_requestor_response`, and `lower(author_email)` equals `lower(created_by_email)`. The insert policy does not bind `author_email` to the JWT. That was already true before this migration.
- The attachment gap is **S29**.

`ticket_email_log_admin_all` requires `is_sso_admin_v2()`. `ticket_type_history_tenant_read` is `{public}` and matches `tenant_id` only. That policy was not part of this migration.
