# Аудит безопасности Sharp Matrix — 2026-09-01

Документ для коллег. Технический EN-отчёт: [2026-09-01.md](2026-09-01.md).  
Метод: [security-audit-runbook.md](../security-audit-runbook.md). Модель и бэклог: [security-model.md](../security-model.md).

**Что сделали в этот проход:** только доказуемо безопасные фиксы (поведение приложений не меняется: сохраняем `authenticated` / `service_role`, отзываем лишний `anon`).  
**Что не делали:** системы в активном тестировании, системы без доказанного пути использования, legacy/sandbox вне презентации.

## Системы по одной

### 1. Matrix SSO (`xgubaguglsnokjyudgvc`) — P0

**Назначение:** единый вход, роли, тенанты, OAuth, JWT.  
**Статус Advisors:** 0 ERROR / 54 WARN.  
**Находки:** S4 — leaked-password protection выключен; был S13 — anon DML на `sso_permission_load_failures`.  
**Решение:** критичные гранты **исправлены** (S13). S4 **не трогаем** (меняет поведение Auth) — в отчёт.  
**Почему безопасно:** пишет EF `log-permission-failure` под `service_role`; SPA вызывают только EF.

### 2. Matrix CDL (`ofzcokolkeejgqfjaszq`) — P0

**Назначение:** общая витрина листингов / RESO / MLS pipeline.  
**Статус:** 0 ERROR / 69 WARN; TRUNCATE и anon DML чистые (S9 держится).  
**Находки:** 30 anon EXECUTE на SECURITY DEFINER (pipeline-мутаторы); открытый S1 (мульти-тенантность).  
**Решение:** EXECUTE **отозван**. S1 — архитектура, без изменений.  
**Почему безопасно:** RPC вызываются из EF под `service_role`; публичное чтение — SELECT `properties_published`, не RPC.
