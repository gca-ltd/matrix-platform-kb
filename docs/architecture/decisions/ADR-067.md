# ADR-067: The usage journal stores what was typed, except secrets, for 30 days

**Status:** Accepted
**Date:** 2026-11-16
**Scope:** Matrix Sales Automation. Replaces point 3 of [ADR-066](ADR-066.md).
**Related:** [ADR-066](ADR-066.md), [security-model.md](../../platform/security-model.md), [compliance.md](../../platform/compliance.md), [product-analytics.md](../../platform/product-analytics.md)

## Context

A click named `Input/5` cannot be read without the form's source. The caption of the control, the field it bound, the option that was chosen, the record it belonged to, and the text that was typed are what make a session reconstructable.

ADR-066 kept the characters out of the journal and left them on the saved business row. That misses text that was typed and never saved, and it makes a field edit unreadable until someone joins it back by hand. The MSA database is under a gigabyte, the broker count is small, and a separate short-lived table holds the text.

## Decision

1. `ui_events` gains `label`, `field`, `href`, `page_query`, and `trigger`. Address parameters named like a token, secret, password, auth, code, or session are dropped.
2. Typed text for `field_edit` and `search` is stored in `ui_event_texts` (`text_before`, `text_after`), at most 4000 characters, and dropped after 30 days. It is never written into `props`.
3. Text is not stored for a password, a hidden field, a file input, a one-time code, or any control under `data-track-off`. A field or target whose name contains `password` is cleared again in SQL.
4. Raw events are kept 90 days. The daily rollup stays. `ui_journal_stats` records the size each night and warns above 3 GB.
5. `ui_action_catalog` names a control. A later edit applies to events already stored. `ui_activity_log` is `security_invoker` and is not granted to `authenticated`. It shows the label, the text, and the opportunity stage at that time. `ui_events_ocel` exports OCEL 2.0 JSON and is owner-only.
6. Insert stays on the caller's JWT. There is no service role and no select for `authenticated`.

## Consequences

- Staff must be told, before this runs in production, that actions are recorded and that what they type is recorded too, except passwords and other switched-off fields. The text is kept 30 days and is readable by the database owner.
- A saved description is still on the opportunity or the note. The journal now also has the draft.
- Session replay remains a later decision.
