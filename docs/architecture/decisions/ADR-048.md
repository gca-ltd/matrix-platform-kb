# ADR-048: Agent-configured chart rendering and image-output conventions

**Status**: Accepted  
**Date**: 2026-08-29  
**Scope**: `gca-ltd/sharpsir-charts-mcp-server`

## Context

Agents need a reliable way to turn structured business data into charts for
reports, decks and inline responses. Browser-side rendering is not available
to every MCP client, and sending data to a third-party image service would
create an unnecessary privacy boundary. A chart server also needs to prevent
model-generated Chart.js callbacks and ad-hoc styling from producing unsafe or
visually inconsistent output.

## Decision

### D1 — Render locally with Chart.js and Skia Canvas

Sharp SIR Charts is a thin MCP utility. It accepts JSON data and renders
server-side with Chart.js and `skia-canvas`. PNG is the default; SVG and PDF
are vector alternatives; JSON exposes the resolved configuration for
inspection. Every image response includes a small PNG preview and the
full-resolution artifact is written to the operator-configured output store.

### D2 — Use a layered, session-scoped design

The resolution order is server default → MCP-session design → per-call
override. The shipped default is `sothebys`, with opt-in `sharp-matrix`,
`mono-print`, and `neutral` references. Partial objects deep-merge and are
strictly Zod-validated. Design state is memory-only and is evicted when an
HTTP MCP session closes.

The SIR reference uses a warm paper surface, SIR Blue `#002349`, Text Grey
`#666666`, Accent Grey `#999999`, and one gold highlight `#BD9042`, with
Playfair Display titles and Inter labels. It applies reduced chrome, direct
labels, zero baselines for bars, and a hairline title rule. The nearby
published `#C29B40` value is documented as a source discrepancy rather than
silently substituted.

Design tokens are authored for a 640×400 logical canvas (chat/Teams display
size). Defaults are width 640, height 400, scale 3. Size-like tokens scale with
`max(width/640, height/400)` so larger canvases change resolution, not layout.
Bars use relative Chart.js percentages with a thickness cap rather than a fixed
thin stroke.

### D3 — Make tool guidance part of the contract

Each tool description includes what it does, when to choose it instead of a
neighbour, inputs, returns, constraints, and JSON examples. Inputs are JSON
only: functions are stripped, inline style conflicts are warned, dimensions
and point counts are bounded, and all tool results carry a warnings array.
Specialized chart tools are preferred over raw Chart.js configuration so agents
choose chart relationships honestly.

## Deliberate divergence from ADR-039

ADR-039 is normative for public MCP Resource Servers that expose protected
Matrix data and use the Qobrix Resource Server / Authorization Server split.
Sharp SIR Charts intentionally does not implement that contract because it is
data-free and only renders caller-supplied values. Stdio relies on process-local
trust. The optional hosted endpoint uses an operator-managed bearer token
behind loopback-bound Apache and exposes no upstream business credentials. If
data tools are added later, this decision expires for that surface and ADR-039
OAuth must be adopted before release.

## Consequences

- Reports can render without a browser or external data service.
- Design changes are isolated to one MCP session and cannot leak between users.
- The image output path requires retention cleanup and operator permissions.
- Brand review remains a release gate because typography and whitespace cannot
  be fully validated by automated tests.

## Follow-up

Audit SPA brand tokens separately: the Pipeline navy/gold values are a
near-match rather than the SIR chart gold, and `--chart-1` through `--chart-5`
are currently undefined in the SPA design surface. This does not alter the
renderer contract.

Exhibit-library review (2026-08-30): string colours are preserved for bullet
bands/measure; connector fills stay opaque; slope no longer shares dumbbell
joins; hand-drawn `drawFrame` lays out title → subtitle → rule → content top-down;
bullet targets use per-row `categoryIndex` ticks; part-to-whole enforces equal
labels/values lengths; exhibit-owned datasets skip sanitize style warnings.

Editorial pass (2026-08-30): vertical end labels inset by `gap` measured to the
glyph top (parity with horizontal); short bars flip outside and clamp on plot
overflow (no end↔outside recursion); line/area labels never sit on the stroke;
translucent fills are composited over the paper before contrast so cream-on-cream
values disappear; the 36px value-label gutter is removed from layout padding so
every orientation shares one title baseline (headroom via value-scale `grace`:
4% for default bar end, 6% for outside/line/area); area charts honour
`areaOpacity`; radial legends force filled circle swatches; line/area use
`cubicInterpolationMode: "monotone"`; the category baseline remains when direct
labels hide value ticks; KPI hairline clears the numeral
(`max(gap·1.25, valueSize·0.35)`) and the sparkline is a bottom-anchored band with
a clamped terminal dot (omitted when fewer than 16px remain); title ink is navy
(`titleBlock.textColor` / series[0]); rule gold is `titleBlock.ruleColor` /
`palette.accent`; `palette.accentInk` is the AA accent stroke for sparklines
(Sharp Matrix cyan, distinct from Sotheby gold).
